Privacy Policy - Video Downloader for Facebook & Threads

Last Updated: November 6, 2026

This extension is an independent project and is not affiliated with, endorsed by, or sponsored by Meta Platforms, Inc., Facebook, or Threads.

隱私權政策（中文摘要）

本擴充功能不收集、不儲存、不傳送任何個人資料。 所有處理都在您的瀏覽器本機完成。為了找出影片的真實網址，擴充功能會在 facebook.com 上讀取頁面內容與頁面向 Facebook 發出的網路回應，但僅用於比對影片網址，不會記錄或傳送到任何伺服器。

1. Information We Collect

This extension does NOT collect, store, or transmit any personal data.
  • No User Data Collection: We do not collect, store, or transmit any personal information, browsing history, or usage data.
  • No Tracking: We do not use analytics, tracking pixels, or any form of user monitoring.
  • No Account Information: We do not access or store your Facebook or Threads account credentials.
  • No Remote Code: All code ships inside the extension package. Nothing is loaded from external servers.

2. Permissions Required

This extension requests the following permissions, and nothing else:

  • downloads: Used to save the selected video to your device through the browser's download manager. A "Save As" dialog is shown so you choose the location.
  • Host access to https://www.threads.net/*, https://www.threads.com/* and https://*.facebook.com/*: Required to show a download button on videos and to read the video URL from those pages. The extension does not run on any other website.

3. How the Extension Works

  • Download Button: A small download button is shown at the top-right corner of each video on Threads and Facebook. The extension only acts when you click that button.
  • Finding the Video URL on Threads: The video URL is read directly from the video element on the page.
  • Finding the Video URL on Facebook: Facebook serves videos through blob URLs that cannot be downloaded directly. To find the real video file, the extension inspects, locally in your browser, the page content and the responses Facebook's own web app receives from facebook.com. It only looks for video URL fields (for example playable_url or progressive_url). This inspection happens entirely on your device; nothing is logged, stored, or sent anywhere.
  • No Data Storage: Video URLs are kept in memory only while the page is open and are discarded when you navigate away or close the tab.
  • File Names: The suggested file name may include the public username shown on the post so you can identify the file. It is not transmitted anywhere.

4. Data Sharing

We do NOT share any data with third parties.
  • No data is sold, rented, or shared with advertisers
  • No data is shared with analytics companies
  • No data is shared with any third-party services

5. Data Security

  • No data is stored, so there is no stored data to secure
  • All operations are performed locally in your browser
  • The only network request the extension itself initiates is the video download, which goes to Meta's content delivery servers (fbcdn.net / cdninstagram.com)

6. Children's Privacy

This extension is not directed to children under 13. We do not knowingly collect any information from children.

7. Changes to This Policy

We may update this privacy policy from time to time. Material changes will be reflected by updating the date at the top of this policy.

8. Contact Us

If you have questions about this privacy policy, please contact us through the Chrome Web Store support page or the project's GitHub repository.

9. Open Source

The source code is publicly available at github.com/blackbear007-maker/MetaVideoDownloader so anyone can verify these commitments.
